# AI靈丹軟體
本AI標注、訓練、辨識與管理軟體，是基於網路架構的邊緣運算私雲服務，彈性化的架構有利於未來擴充於於公雲SaaS端服務。緣運算私雲服務能確保使用者的資料集在企業內部，不會有資料外洩的疑慮，公雲服務亦可提供便捷的SaaS端服務。整體系統架構彈性兼顧未來擴充性。

又由於影像標記服務需要管理大量照片與標記資料集，一般而言、一個AI辨識物種需要日夜間各個角度照片3000張及標記，本軟體提供半自動標記服務增加標記效率，亦能夠批次上船已經標記好的資料集。此外本系統已經系統化支援YOLOv5、YOLOv7、YOLOv8、YOLOv11、YOLOv11 segmeation 的指令集，無須具程式設計背景便可進行繁瑣的AI模型訓練，完成AI模型的辨識與推論，進而管理每一個經長時間訓練的模型。

# Ailixir Software
This AI annotation, training, inference, and management software is a web-based edge computing private cloud service. Its flexible architecture facilitates future expansion into public cloud SaaS services. The edge computing private cloud service ensures that users' datasets remain securely within the enterprise, eliminating concerns about data leaks, while public cloud deployments can also offer convenient SaaS solutions. The overall system architecture perfectly balances flexibility with future scalability.

Moreover, image annotation services require managing massive amounts of photos and labeled datasets. Generally, training an AI to recognize a single object class requires around 3,000 photos and annotations taken from various angles during both day and night. To address this, our software provides semi-automatic annotation features to enhance labeling efficiency and supports the batch uploading of pre-labeled datasets.

Furthermore, the system systematically supports the command sets for YOLOv5, YOLOv7, YOLOv8, YOLOv11, and YOLOv11 segmentation. Users can execute complex AI model training, complete AI model inference, and manage each extensively trained model without needing any programming background.

# Italiano
Software Ailixir

Questo software di annotazione, addestramento, inferenza e gestione AI è un servizio cloud privato di edge computing basato sul web. La sua architettura flessibile facilita la futura espansione verso servizi SaaS su cloud pubblico. Il servizio cloud privato di edge computing assicura che i dataset degli utenti rimangano al sicuro all'interno dell'azienda, eliminando le preoccupazioni relative alle fughe di dati, mentre il cloud pubblico può offrire comode soluzioni SaaS. L'architettura complessiva del sistema bilancia perfettamente flessibilità e scalabilità futura.

Inoltre, i servizi di annotazione delle immagini richiedono la gestione di enormi quantità di foto e dataset etichettati. In genere, l'addestramento di un'IA per riconoscere una singola classe di oggetti richiede circa 3.000 foto e annotazioni da varie angolazioni, sia di giorno che di notte. Per risolvere questo problema, il nostro software fornisce funzioni di annotazione semi-automatica per aumentare l'efficienza dell'etichettatura e supporta il caricamento in blocco di dataset già etichettati.

Inoltre, il sistema supporta sistematicamente i set di comandi per YOLOv5, YOLOv7, YOLOv8, YOLOv11 e YOLOv11 segmentation. Gli utenti possono eseguire complessi addestramenti di modelli AI, completare l'inferenza dei modelli AI e gestire ogni modello ampiamente addestrato senza alcuna conoscenza di programmazione.

# 日本語
Ailixir ソフトウェア

本AIアノテーション、トレーニング、推論、および管理ソフトウェアは、Webベースのエッジコンピューティング・プライベートクラウドサービスです。その柔軟なアーキテクチャは、将来的なパブリッククラウドSaaSサービスへの拡張を容易にします。エッジコンピューティングによるプライベートクラウドサービスは、ユーザーのデータセットが企業内に安全に保持されることを保証し、データ漏洩の懸念を排除する一方で、パブリッククラウドは便利なSaaSソリューションを提供することも可能です。システム全体のアーキテクチャは、柔軟性と将来の拡張性を完璧に兼ね備えています。

また、画像アノテーションサービスでは、膨大な量の写真とラベル付けされたデータセットを管理する必要があります。一般的に、1つのAI認識対象（クラス）につき、昼夜を問わず様々な角度から撮影された3,000枚の写真とアノテーションが必要です。これに対応するため、本ソフトウェアはラベル付けの効率を高める半自動アノテーション機能を提供するほか、すでにラベル付けされたデータセットの一括アップロード機能もサポートしています。

さらに、本システムはYOLOv5、YOLOv7、YOLOv8、YOLOv11、およびYOLOv11セグメンテーション（segmentation）のコマンドセットを体系的にサポートしています。プログラミングの知識がなくても、複雑なAIモデルのトレーニングを実行し、AIモデルの推論を完了させ、長時間をかけてトレーニングされた各モデルを容易に管理することができます。
